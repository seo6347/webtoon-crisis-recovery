# webtoon-crisis-recovery

Analysis of webtoon crises and recovery patterns using episode ratings and reader comments.

## Running the analysis

See [Environment and execution](docs/setup.md) for dependencies, prepared-data placement, and notebook instructions. Start at **Step 5** of [webtoon_crisis_recovery.ipynb](webtoon_crisis_recovery.ipynb); Steps 1–4 are historical collection/cleaning code.

The analysis uses the prepared data and finalized labels. Live scraping and LLM labeling are not rerun.
